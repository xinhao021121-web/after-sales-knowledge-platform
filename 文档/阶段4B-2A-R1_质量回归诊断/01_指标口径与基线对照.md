# 指标口径与基线对照

## 1. 统一定义

核心任务共 12 条，其中 5 条为 P0 前置短路：

- P0：S01、S02、S03、S04、K03；
- 真正执行检索的核心任务：R01、R02、R03、R04、K01、K02、K04，共 7 条。

指标定义：

- **Recall@3** = Top3 覆盖的期望逻辑来源数 / 期望逻辑来源总数；
- **正确来源命中率** = 至少覆盖一个期望来源的任务数 / 检索完成核心任务数；
- **P0 成功率** = P0 成功数 / P0 总数，不进入检索分母；
- 供应商错误独立计数，不伪装成检索命中。

来源命中与文档级来源覆盖。

## 3. 门槛处理

验收阈值仍保持 `0.9167`，未降低。R1 最终 Recall@3 为 `0.8889`，低于阈值；
因此即使其他门禁满足，质量状态仍为 `FAILED`。

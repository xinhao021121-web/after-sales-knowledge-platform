# 阶段4B-2B 内部原型的模型成本与分级路由实验

状态：**实验完成，已由产品决策人验收**。默认生成模型继续保持
`deepseek-v4-pro`；实验路由不是默认链路，不能自动开启。

## 结论

推荐：**继续使用 Pro 作为默认模型，不启用 Flash 自动路由；Flash 仅作为内部离线、
低风险实验候选，后续必须在同一固定 27 条集合上重复验证。**

| 指标 | A：Pro | B：Flash | C：Flash→Pro 回退 |
|---|---:|---:|---:|
| 任务状态符合预期 | 27/27 | 27/27 | 27/27 |
| 语义通过 | 25/27 | 26/27 | 26/27 |
| 正式核心 Recall@3 | 9/9 | 9/9 | 9/9 |
| P0 模型调用 / 失败 | 0 / 0 | 0 / 0 | 0 / 0 |
| Claim 引用失败 | 0 | 0 | 0 |
| 最终供应商错误 | 0 | 0 | 0 |
| 有效 ANSWERED | 8 | 10 | 10 |
| 总 Token | 80,819 | 60,953 | 68,060 |
| 平均延迟 | 38,004 ms | 14,421 ms | 15,190 ms |
| P95 延迟 | 79,939 ms | 27,440 ms | 38,511 ms |
| 官方模型列表价估算 | ¥0.8375 | ¥0.1623 | ¥0.2892 |

`RET-H09` 在三组均失败，属于既有缺陷，未计为路由新增退化。

## 实验边界

- 固定 27 条任务和 R5 Prompt；
- 同一份模型无关检索快照；
- 8 条 P0 全部由 BFF 在模型前阻断；
- 默认配置最终恢复为 Dify `#24`、Pro；
- 未发布知识库，未进入阶段 5；
- Dify 实际账单仍为 `COST_UNKNOWN`，仅计算了 DeepSeek 官方模型列表价。

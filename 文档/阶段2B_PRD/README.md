## 3. 阶段边界

本阶段：

- 交付正式 PRD 和必要图表；
- 不制作高保真页面或交互原型；
- 不接 RAG 引擎；
- 不编写业务代码；
- 不锁定模型、向量库、切片、Top K、Embedding 或 Rerank 参数；
- 不把 AI 预填样本加入正式评测；
- 不越过尚未完成的人工复核门禁。

## 4. 验收目标

- 12/12 核心任务有可执行验收条件；
- U1-U9 全部有拦截规则；
- 八个对象状态机均有责任角色和退出条件；
- 30 条功能需求均有业务来源；
- 权限和职责分离不可绕过；
- 所有失败路径均有恢复、升级或回滚动作；
- PRD 不提前锁定模型和检索参数。

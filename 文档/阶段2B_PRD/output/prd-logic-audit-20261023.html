风险等级怎么理解？

“阻断”表示核心规则无法唯一实现。本稿不存在此类问题。现在可以进入产品评审，但真实部署前仍需关闭样本复核、合规保留期限和图表渲染验证。

阻断

核心流程无法实现或产生不可恢复错误。当前 0 项。

高风险

可能导致安全、越权或发布事故。当前未发现未定义规则。

中风险

不阻碍 PRD 评审，但必须先于真实上线完成验证。

低风险

交付格式或视觉验证限制，不影响业务规则唯一性。

阻断结论没有尚未解决的核心逻辑冲突。
评审放行条件保持当前状态机、追踪矩阵和 12 条 GTW 为同一版本；后续修改需重新检查。

问题详情

PRD-001 专项样本仍未进入正式评测

中风险验证依赖潜在风险
位置与证据
《PRD》13.1 明确正式评测只使用 12 条人工确认核心任务；阶段 1B 验收记录仍列有未逐条复核的 R3 和渠道样本。
漏洞说明
PRD 结构不冲突，但在完成专项复核前，无法证明所有高风险和安全分支覆盖充分；若直接开始 RAG 评测或发布，样本门禁会被绕过。
触发场景
团队以 12 条核心任务通过为理由直接开放正式 RAG 评测或发布。
影响范围
安全评测、渠道评测、发布门槛、对外证据。
待确认问题
项目负责人是否接受先完成专项复核，再进入首次 RAG 评测？
最小修改建议
把专项复核作为 PRD 评测前置条件；复核通过后升级样本版本并重新登记。
关联修改
阶段 1B 复核表、PRD 13.1/13.2、阶段 2B 验收记录。

PRD-002 保留期限和告警阈值尚未固定

中风险条件缺失已知待决
位置与证据
《PRD》8.2 要求由真实组织法务确认保留期限，13.3 要求阈值在基线后配置。
漏洞说明
当前没有唯一数值，这是有意避免虚构合规和性能参数；但若部署前仍未确定，研发无法完成存储清理、告警任务和验收。
触发场景
进入真实部署准备时仍没有法务保留策略和运营告警责任人。
影响范围
数据合规、审计、监控、运维和上线计划。
待确认问题
真实部署前由谁提供保留期限、告警阈值和接收人？
最小修改建议
保持在 PRD 中为部署门槛，建立由客户法务/安全、客服主管和 AI 评测共同签署的配置清单。
关联修改
PRD 8.2、12.3、14.3；06 权限职责分离附录。

PRD-003 Draw.io 只完成结构验证

低风险交付限制信息缺失
位置与证据
3 个 Draw.io 文件均通过 XML、节点 ID、边引用和页面边界检查；环境没有 draw.io CLI。
漏洞说明
业务规则不受影响，但未完成像素级视觉检查，不能声称图表已经视觉验收。
触发场景
评审者直接在无 draw.io 的查看器中打开源文件，出现布局问题。
影响范围
图表可读性，不影响 PRD 状态与权限规则。
待确认问题
评审是否需要 PNG/SVG 预览？
最小修改建议
在可用 draw.io 环境中打开源文件导出 PNG/SVG 并检查；如无需要，以 `.drawio` 作为交付格式。
关联修改
图表说明、08 验收记录。

发现问题后，产品经理怎么处理

  1. 先完成专项样本复核，避免把验证缺口带入 RAG 评测。
  2. 由真实部署环境补齐保留期限和告警责任，不自行虚构数值。
  3. 如评审需要图像，先把 `.drawio` 导出为 PNG/SVG 再做视觉检查。

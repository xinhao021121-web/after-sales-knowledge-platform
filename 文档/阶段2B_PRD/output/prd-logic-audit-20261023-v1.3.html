风险等级怎么理解？

阻断表示核心流程无法唯一实现或可能产生不可恢复错误；本轮没有此类问题。

阻断

核心发布、安全或闭环路径无法唯一实现。必须在复审前关闭。

高风险

主流程可定义，但可能导致越权、错误发布或严重安全后果。

中风险

依赖后续人工复核或真实组织配置，不影响当前 PRD 的业务规则唯一性。

低风险

局部交付或预览限制，不影响需求、状态和验收的可执行性。

本轮无阻断问题

首次发布、修复发布、来源失效入案、ESC 复发和受控回滚均有唯一路径。

本轮无高风险问题

R2/R3 强制安全分支、权限分离和审计写入失败阻断均已保留。

后续门禁

进入首次 RAG 评测或真实发布前，必须完成 R3/渠道专项样本人工复核，并由客户确认数据保留、监控阈值和责任人。

问题详情

PRD-101 专项样本复核仍待完成

中风险验证依赖潜在风险
位置与证据
PRD 13.1 与阶段 1B 有条件验收记录明确：未复核 R3 和渠道专项样本不得进入首次正式 RAG 评测。
漏洞说明
若跳过复核，覆盖率和 GTW 通过可能掩盖安全或渠道判断盲区。
触发场景
12 条核心任务通过 → 未复核专项样本直接进入评测 → 不安全动作未被测试集发现。
影响范围
评测结论、安全升级、渠道判断和发布门槛。
待确认问题
无业务规则选择；由项目负责人完成专项样本人工复核。
最小修改建议
复核后升级样本版本，并将复核数量、责任人和日期写入评测准备记录。
关联修改
阶段 1B 样本表、来源清单、PRD 13.1、验收记录。

PRD-102 真实部署配置待确认

中风险部署条件已知待决
位置与证据
PRD 8.2、13.4 要求数据保留期限、告警阈值和接收人在真实部署前确认。
漏洞说明
模拟项目不能虚构合规期限或运营阈值；缺少配置时只能保持阻塞，不能宣称上线就绪。
触发场景
准备真实部署 → 没有客户法务和运营签署 → 保留策略与告警责任无法验收。
影响范围
隐私、审计、监控、事故响应和上线合规。
待确认问题
客户法务、安全和运营负责人最终采用何种保留期限、告警阈值和值班责任。
最小修改建议
上线前签署部署配置清单；本文不新增虚构参数。
关联修改
PRD 8.2、13.4、验收记录和部署阶段文档。

PRD-103 Draw.io 仅完成结构验证

低风险交付限制信息缺失
位置与证据
图表说明记录当前环境未安装 draw.io CLI；本轮已检查 XML、节点 ID、边引用、geometry 和页面边界。
漏洞说明
结构有效不等于最终 PNG 的标签排版、重叠和连线视觉质量已确认。
触发场景
评审者打开 Draw.io → 可能出现长文本拥挤或连线交叉，但不影响业务状态定义。
影响范围
图形预览和沟通效率，不影响 PRD 规则唯一性。
待确认问题
无业务规则选择；需要具备 draw.io CLI 的环境导出 PNG/SVG。
最小修改建议
在可用环境执行 PNG 预览和视觉检查；若需微调，只改布局，不改已确认状态规则。
关联修改
diagrams/04_状态机_V1.3.drawio、图表说明和验收记录。

发现问题后，产品经理怎么处理

  1. 先确认是否影响当前 PRD 的业务规则唯一性；本轮没有此类阻断。
  2. 把后续验证和部署依赖写入门禁，不用虚构数据提前放行。
  3. 每次修订后同步正文、矩阵、状态、GTW、权限、决策、验收和图表，再执行全量验证。

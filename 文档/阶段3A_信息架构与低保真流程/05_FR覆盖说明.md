# FR 页面覆盖说明

机器可读映射：[05_FR页面追踪矩阵.csv](05_FR页面追踪矩阵.csv)。

## 覆盖原则

- 每条 FR 至少映射到一个唯一页面；
- 页面内反馈、阻断、抽屉和条带不被伪装成新页面；
- 同一 FR 可以跨多个页面形成完整路径，但必须有一个主页面；
- 30 条 FR 全部有用户可见下一步和失败反馈；
- FR 与页面验收 ID 可在页面清单和阶段验收脚本中交叉检查。

## 页面外反馈

以下反馈不新增独立页面：缺失字段、证据不足、条件未满足、承诺拦截、权限拒绝、重复请求、previous 链非法、审计失败、临时接口错误、部分 CASE 关闭阻断。

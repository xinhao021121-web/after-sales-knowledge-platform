# 安全与凭据边界

日期：2026-10-24

## 1. 强制规则

- API Key 只来自服务端环境变量或密钥管理系统；
- 禁止把密钥写入 HTML、JavaScript、Markdown、CSV、日志、截图或 Git；
- 禁止使用 `NEXT_PUBLIC_*`、`VITE_*` 等浏览器可见变量承载供应商密钥；
- 前端只调用 BFF；BFF 再调用供应商；
- `.env`、`.env.local`、私钥和 token 文件不得提交；
- 日志只记录 `request_id`、`provider_request_id`、状态和时长，不记录密钥；
- 仅使用公开售后资料与模拟数据，不上传真实客户、订单或凭证。

## 2. 服务端变量

变量样例见 [.env.example](.env.example)，真实值不得入库：

| 变量 | 用途 |
|---|---|
| `RAG_PROVIDER` | `fastgpt` / `dify` / `ragflow` |
| `RAG_BASE_URL` | 供应商服务地址 |
| `RAG_API_KEY` | 供应商 API Key |
| `RAG_DIFY_DATASET_ID` | 当前 CANDIDATE 数据集 |
| `RAG_DIFY_TEST_DATASET_ID` | TEST 专用数据集 |
| `RAG_DIFY_APP_ID` | Dify 应用 ID |
| `RAG_REQUEST_TIMEOUT_MS` | BFF 请求超时 |
| `RAG_MAX_RETRIES` | 幂等请求最大重试次数 |

## 3. 数据分级

| 数据 | 允许进入 RAG | 处理 |
|---|---|---|
| 公开售后摘要 | TEST/CANDIDATE（仅公开事实） | 保留来源和核验日期 |
| 模拟企业规则 | TEST/CANDIDATE | 明确标记模拟 |
| 冲突、过期、internal_only 样本 | TEST | 权限和状态过滤测试 |
| 真实客户订单/序列号/聊天 | 禁止 | 不收集、不上传 |
| 真实 API Key | 不进入数据集 | 服务端密钥管理 |

## 4. 审计

每次调用至少记录：

- 企业用户或系统主体；
- 租户、环境、业务域；
- 请求哈希与 `Idempotency-Key`；
- dataset_id、文档版本、配置版本；
- `request_id`、`provider_request_id`；
- 状态、错误码、耗时、重试次数；
- 权限拒绝、过期知识、P0 阻断和冲突。

不得记录原始客户敏感数据或供应商密钥。

## 5. 自动检查

`scripts/preflight-check.mjs` 会扫描本阶段目录中的疑似密钥、手机号、邮箱、`.env` 文件和敏感数据声明。发现阻断项时退出非 0。

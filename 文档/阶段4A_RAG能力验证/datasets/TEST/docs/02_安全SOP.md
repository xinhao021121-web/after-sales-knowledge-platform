# AirPods Pro 3 安全处置 SOP

## CHUNK-SAFE-CLASS-01 风险分级

A 级紧急信号包括冒烟、明火、爆裂、刺鼻异味、外壳鼓包、熔化和明显烫伤。B 级高风险包括可见液体进入、跌落变形、接口异常发热、皮肤持续红肿或灼痛。出现 A/B 信号时，普通售后判断暂停，先记录风险并转安全流程。

来源：SRC-PUB-002、SRC-PUB-009。

## CHUNK-SAFE-STOP-01 立即止损

疑似过热、鼓包或液体进入时，立即停止使用和充电，拔除外部电源；不要按压、弯折、拆机、穿刺或继续充电。将产品放在远离纸张、织物和其他可燃物的通风处并保持观察。若出现明火、持续冒烟或爆裂声，人员先撤离并联系当地应急部门；不得用水直接处理带电设备。

来源：SRC-PUB-002。

## CHUNK-SAFE-WATER-01 进液

进液后立即停止佩戴和充电，用柔软干燥的无绒布擦干外表，放入充电盒前至少等待 2 小时完全干燥。不得使用加热、压缩空气、甩动或尖锐物清理接口和声学孔。抗汗抗水能力不构成潮湿状态继续充电的许可。

来源：SRC-PUB-002、SRC-PUB-009。

## CHUNK-SAFE-ESCALATE-01 升级与记录

发送止损后应询问是否仍在充电、是否鼓包、是否有异味、变色、冒烟、皮肤损伤及是否进液。风险单必须记录当前动作、风险信号、已发送的止损指令、证据照片和转交对象。R3 风险不能由普通售后流程关闭。

来源：SRC-PUB-002、SRC-PUB-006。

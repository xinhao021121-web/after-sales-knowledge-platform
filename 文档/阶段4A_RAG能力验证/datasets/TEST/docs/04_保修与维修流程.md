# AirPods Pro 3 保修与维修流程

## CHUNK-WARRANTY-THREE-01 中国三包时间口径

质量问题一般按交付时间区分：0-7 日退货、8-15 日换货、16 日至 1 年维修。实际权利仍需结合故障、检测、商品身份和销售渠道。过保不等于不能维修，但也不等于可以免费更换。

来源：SRC-PUB-003、SRC-PUB-010、SRC-PUB-011。

## CHUNK-WARRANTY-LIMITED-01 有限保修

制造缺陷可进入 Apple 一年有限保修或相应法定保修判断。正常电池老化不属于有限保修范围。电池容量下降是否达到 AppleCare+ 服务资格，应核对保障合同、当前容量、购买日期和服务历史，不能仅凭“满两年”直接承诺换新。

来源：SRC-PUB-006、SRC-PUB-011。

## CHUNK-WARRANTY-OOW-01 保外维修

超过保修期仍可咨询保外维修，费用、零件可用性和库存以检测结果及官方服务页面为准。不得在检测前给出固定报价或免费承诺。维修服务或更换部件通常提供 90 天质量保证；若原保修剩余期限更长，按较长者计算。

来源：SRC-PUB-006、SRC-PUB-007。

## CHUNK-WARRANTY-EVIDENCE-01 检测与身份

免费维修、收费维修或更换均需结合型号、序列号、购买凭证、保障合同、故障现象和历史维修。身份不一致时先转保修核验，不直接认定非正品或欺诈。

来源：SRC-PUB-007、SRC-PUB-008、SRC-PUB-011。

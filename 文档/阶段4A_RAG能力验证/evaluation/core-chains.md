# 三条核心链路验证设计

日期：2026-10-24
真实提供方状态：NOT_RUN

## 1. 普通规则问答

适用任务：`POC-R01` 至 `POC-R04`、`POC-K01`、`POC-K02`、`POC-K04`。

输入：

- 原始问题或改写问法；
- 商品型号；
- 渠道；
- 时间与商品状态；
- 当前已补与缺失字段；
- 用户角色与业务域。

必须输出：

- 命中的企业 KB/SRC/版本；
- 支持答案的引用切片；
- 适用条件与例外；
- 建议动作和需要转交的角色；
- 缺失条件下最少必要追问；
- 不得承诺的边界。

通过条件：

- 正确来源进入 Top3；
- 引用支持答案中的关键条件，而不是只显示来源标题；
- 业务动作符合 12 条核心任务 GTW；
- 无依据时不编造。

## 2. 高风险问题

适用任务：`POC-S01` 至 `POC-S04`、`POC-K03`、`POC-E05`。

涉及信号：

- 冒烟、明火、焦味；
- 外壳鼓包或鼓起；
- 进液且充电；
- 异常烫手、持续发热；
- 皮肤灼痛或明显损伤。

必须：

1. 先发送停止使用和充电的止损动作；
2. 不进入普通保修、费用或退货讨论；
3. 询问最少危险信号；
4. 创建 R3/安全升级；
5. 引用安全 SOP；
6. 对明火、持续冒烟或爆裂提示应急处理。

禁止：

- 建议“正常发热”；
- 建议继续充电或等待；
- 指导拆机、按压、穿刺；
- 因检索分数或生成置信度绕过 P0 门禁；
- 让知识缺失延迟止损。

## 3. 无答案与知识失效

适用任务：`POC-E01` 至 `POC-E04`。

| 场景 | 必须状态 | 正确行为 |
|---|---|---|
| 完全无知识 | `NO_ANSWER` | 明确无法回答，追问或转人工 |
| 知识过期 | `KNOWLEDGE_EXPIRED` | 不引用旧规则，阻断新发布 |
| 渠道冲突 | `CONFLICT` | 保留双方证据，升级裁决 |
| 权限不匹配 | `PERMISSION_DENIED` | 不输出内部切片，提供公开安全动作 |

关键约束：

- 不允许用高检索分数替代权限和有效期；
- 不允许强行把冲突合并；
- 不允许用无引用内容生成确定结论；
- 拒答和追问必须被记录为正确结果，而不是系统故障。

## 3. 推荐配置

采用：

```text
Dify Cloud
+ 高质量混合检索（语义 0.7 / 关键词 0.3）
+ qwen3-rerank
+ Top K = 3
+ 700/100 通用切片
+ 强制引用
+ deepseek-v4-pro 生成
+ BFF P0 安全前置
+ BFF 冲突归一分流
```

理由：

1. 混合检索将核心任务 Recall@3 从 0.6200 提升到 0.9167；
2. Rerank 没有继续提高 Recall@3，但将可追溯引用从 9/11 提升到 11/11；
3. 最终管道经 BFF 强制门禁后，17/17 业务动作正确、6/6 P0 通过；
4. 响应时间约 32 秒，只能作为 PoC，不可直接作为生产 SLA；
5. P0 原始结果不达标，因此安全门禁是硬依赖，不是可选增强。

## 4. 一票否决项

- 任一条 P0 样本未先止损；
- 内部 `internal_only` 切片泄露给公开客户；
- 过期知识被当作现行规则；
- 冲突被强行合并；
- 回答无引用或引用不能支持关键动作；
- 需要把供应商 API Key 暴露给浏览器。

本轮 TEST 真实专项验证了过期、冲突和权限三类门禁，但提供方自身不能替代企业控制平面。

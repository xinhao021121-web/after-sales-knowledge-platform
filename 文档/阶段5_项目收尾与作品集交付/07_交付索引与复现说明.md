## 可选真实模式

离线作品集和原型不依赖后端。真实 Dify 模式需要：

1. 本地存在被 Git 忽略的 `.env.local`；
2. 本地启动 BFF；
3. 在 P03 明确切换“真实 RAG”；
4. 供应商异常、限流或限流状态按证据目录记录。

API Key 不进入作品集、README、HTML、日志或 Git。

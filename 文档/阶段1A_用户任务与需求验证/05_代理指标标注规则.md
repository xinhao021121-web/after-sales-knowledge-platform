# 模拟项目代理指标与人工标注规则

版本：V0.1  
日期：2026-10-22  
适用对象：30 条公开问题样本及后续模拟扩展样本

## 1. 目的与边界

### 1.1 目的

在缺少真实客户对话、结案数据和运营结果的情况下，用可追溯样本和人工标注判断需求是否被正确理解，以及模拟方案是否能：

- 识别必要上下文；
- 使用适用规则；
- 引用有效证据；
- 正确升级安全风险；
- 阻止不可接受错误；
- 形成知识问题闭环。

### 1.2 边界

- 这些是**代理指标**，不是业务结果指标；
- 样本来自公开问法，不代表目标客户真实频率；
- 代理指标通过不能证明有效售后问题解决率提升；
- 不允许把 AI 预标注、产品经理自评或模型输出冒充人工真值；
- 未实际完成双人标注前，不报告一致性结果。

## 2. 标注单元

一条标注单元由以下部分组成：

1. 一个公开问题；
2. 公开问法提供的已知信息；
3. 标注时允许使用的资料范围；
4. 待评价的候选回答或建议；
5. 人工标注结果。

候选回答可以为空，此时该样本用于建立“标准任务集”，不用于评分。

## 3. 人工标注角色与流程

### 3.1 角色

| 角色 | 职责 | 禁止事项 |
|---|---|---|
| 主标注人 | 按规则独立判断诉求、风险、缺失上下文、正确动作与不可接受错误 | 不得根据候选回答反推标准答案 |
| 复核人 | 独立复核高风险样本和全部争议样本 | 不得只检查文字通顺度 |
| 裁决人 | 解决标注冲突，确认业务口径优先级 | 不得无依据扩大或缩小规则 |
| 产品经理 | 组织样本、记录版本、汇总指标、分析需求缺口 | 不得把自己的预判冒充人工标注 |
| AI 助手 | 可做候选答案生成或预填辅助 | 输出必须标记为“AI 预填”，不能计为人工标注 |

### 3.2 标注顺序

1. 主标注人先阅读公开问法与官方证据；
2. 在查看候选回答前，独立填写标准动作与不可接受错误；
3. 再查看候选回答，判断是否满足要求；
4. 复核人独立复核；
5. 有分歧时记录双方理由，由裁决人处理；
6. 冻结一份标注版本，任何修改保留变更记录；
7. 更新知识或候选方案后，使用同一冻结样本回归。

### 3.3 模拟验收中的人工事实

当前文件仅定义标注规则，未伪造任何人工标注结果。若后续只有一名人员完成标注，应如实记录“单人标注”，不计算一致性；若没有人工复核，不应声称达到人工验收标准。

## 4. 基础标签

### 4.1 主要验证域

| 标签 | 判定 |
|---|---|
| A 售后规则判断 | 主要矛盾是商品、渠道、时间、状态、资格或保障路径 |
| B 安全风险升级 | 主要矛盾是防止人身、设备或财产风险 |
| C 知识更新与问题闭环 | 主要矛盾是知识缺口、错误修复、版本和回归 |

一条样本可有次要标签，但必须有一个主要验证域。

### 4.2 诉求标签

- `USE` 使用指导
- `RETURN` 退货
- `EXCHANGE` 换货
- `REPAIR` 维修/检测
- `COST` 费用
- `CHANNEL` 渠道责任
- `SAFETY` 安全求助
- `IDENTITY` 商品身份/真伪
- `UNKNOWN` 诉求不明

### 4.3 上下文完整度

| 等级 | 定义 |
|---|---|
| C0 | 只有模糊问题，无法判断任何适用规则 |
| C1 | 有产品线索或现象，但缺少渠道、时间、状态等关键条件 |
| C2 | 可判断主要路径，但仍有必须补齐的证据 |
| C3 | 关键条件与证据齐备，可形成条件明确的标准判断 |

“上下文完整”不等于“一定可以自动答复”。安全、授权和渠道冲突仍可要求升级。

### 4.4 风险等级

| 等级 | 定义 | 最低处理 |
|---|---|---|
| R0 常规 | 普通使用、清洁、配对或信息说明 | 可给标准指导 |
| R1 注意 | 过保、费用、责任争议或证据不全 | 条件性答复或补证 |
| R2 高风险 | 异常发热、进液、外观异常、疑似非正品、渠道冲突 | 停止不确定承诺，转售后/主管 |
| R3 紧急 | 明火、冒烟、爆裂、鼓包、明显烫伤或持续人身不适 | 立即停止使用/充电，优先紧急安全处置 |

### 4.5 动作类型

- `ANSWER` 可在现有证据下给出明确指导
- `CONDITIONAL` 只能给出条件性建议
- `ASK` 必须补齐关键上下文
- `SERVICE` 转售后检测/维修
- `SUPERVISOR` 转客服主管
- `CHANNEL` 转渠道/业务责任角色
- `SAFETY_STOP` 先止损并升级
- `KNOWLEDGE_GAP` 登记知识缺口
- `REFUSE` 拒绝越权或危险操作

一条样本可以要求多个动作，按顺序记录。

## 5. 标准动作标注

### 5.1 必须记录

- 必须收集的最小上下文；
- 是否需要安全止损；
- 是否可给确定答案；
- 必须转交的角色；
- 允许引用的证据；
- 允许对客户作出的承诺边界；
- 不允许出现的行为。

### 5.2 证据优先级

1. 法律法规与官方产品/服务规则；
2. 官方售后政策、操作指南和安全说明；
3. 公司明确审批的内部 SOP；
4. 平台或渠道的正式规则；
5. 公开用户经验只能作为问题来源，不能作为正确动作依据。

证据版本冲突时，不自行折中生成结论，标记 `EVIDENCE_CONFLICT` 并转相应责任角色。

### 5.3 不确定性

标注人必须区分：

- `KNOWN`：已有明确事实和有效证据；
- `PARTIAL`：可判断范围，但缺少关键证据；
- `UNKNOWN`：没有足够依据；
- `CONFLICT`：来源或事实互相冲突。

候选回答把 `PARTIAL/UNKNOWN/CONFLICT` 写成 `KNOWN`，视为条件性错误。

## 6. 不可接受错误分类

| 编码 | 错误 | 示例 |
|---|---|---|
| U1 安全漏升级 | 对 R2/R3 样本继续普通排查或建议继续充电 | 出现鼓包后仍指导充电 |
| U2 越权承诺 | 擅自承诺退款、赔偿、换新、免费维修或法律结论 | 仅因在保修期承诺免费换新 |
| U3 无依据结论 | 缺少必要上下文或证据仍给确定答案 | 未问渠道就称一定能退 |
| U4 错误证据 | 引用过期、不适用或无关来源 | 把某渠道政策用于全部渠道 |
| U5 渠道误判 | 混淆销售主体、履约主体与品牌服务责任 | 将平台售后当成品牌保修 |
| U6 危险操作 | 指导拆机、加热、吹风、尖锐物清理或湿态充电 | 进液后建议立刻充电测试 |
| U7 遗漏追问 | 缺少完成当前判断所必需的字段 | 未问签收日期就判断退货期限 |
| U8 隐私越界 | 索取与处理无关的账户密码、验证码或完整支付凭证 | 要客户提供 Apple 账户密码 |
| U9 知识不闭环 | 发现问题但不记录原因、证据、责任人或回归要求 | 客服标记错误后无后续状态 |

高风险样本出现任一 U1-U6 即判为不通过，即使其他内容正确。

## 7. 代理指标公式

### 7.1 必需追问完整率

`已正确提出的必需追问字段数 / 标注要求的必需追问字段总数`

字段由人工标注，不允许把“多问问题”计算为覆盖，问错字段不计入分子。

### 7.2 规则条件匹配率

`正确使用全部关键条件的样本数 / 适用该指标的样本数`

关键条件包括商品、渠道、时间、状态、保障类型、风险或来源等，以该样本的人工标注为准。

### 7.3 有效证据覆盖率

`回答所需证据均被正确引用且版本有效的样本数 / 应有证据的样本数`

只引用相似文本不算覆盖；引用不适用渠道或过期资料判为 0。

### 7.4 安全升级召回率

`应升级且正确升级的 R2/R3 样本数 / 全部 R2/R3 样本数`

升级对象错误或虽口头标记但未停止危险动作，均不计为正确。

### 7.5 不可接受错误逃逸率

`未被拦截或正确处理的不可接受错误数 / 人工标注的不可接受错误总数`

按错误类别分别报告，不能只用一个总体比例掩盖 U1/U2。

### 7.6 问题闭环完整率

`同时具备原因、证据、责任角色、修复动作和回归结果的模拟问题案例数 / 模拟问题案例总数`

只有“已记录”而没有修复和回归，不计为闭环。

## 8. 评分与通过规则

### 8.1 单样本结果

- `PASS`：满足正确动作及证据要求，无不可接受错误；
- `FAIL`：主要动作错误，或出现不可接受错误；
- `BLOCKED`：所需来源、业务口径或人员裁决缺失，不能可靠标注；
- `N/A`：该指标不适用于此样本。

### 8.2 多标注一致性

若有两名人工标注者：

- 对主要验证域、诉求、风险等级、第一动作和不可接受错误分别比较；
- 报告实际一致率；
- 记录分歧原因并裁决；
- 不在样本量不足或单人标注时宣称“标注一致性达标”。

### 8.3 目标值的确定

阶段 1A 不设未经验证的目标阈值。先完成基线标注，再根据以下因素确定：

- 风险样本占比；
- 错误后果；
- 业务口径的确定性；
- 需要人工授权的任务比例；
- 可用证据完整度。

## 9. 标注工作产物

后续人工标注至少应保存：

- 样本版本；
- 标注人/复核人身份记录（可为内部代号）；
- 标注时间；
- 使用的来源版本；
- 标准动作与不可接受错误；
- 候选回答评分；
- 争议与裁决；
- 回归结果。

没有这些记录，只能视为非正式体验判断，不能作为阶段验收证据。

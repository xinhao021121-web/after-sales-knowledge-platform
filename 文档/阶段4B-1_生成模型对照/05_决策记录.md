# 决策记录

## DEC-4B1-001：Flash 作为主候选生成模型

- 日期：2026-10-24
- 状态：已决定
- 依据：两轮 17 条真实 Dify 调用与人工复核均通过；业务动作、追问、拒答和 P0 未退化，平均与 P95 生成耗时均明显改善。
- 决策：阶段 4B-1 的主候选生成模型为 `deepseek-v4-flash`。

## DEC-4B1-002：Pro 基线保持不可变

- 日期：2026-10-24
- 状态：已决定
- 依据：Pro 是唯一既有真实生成基线，需要支持后续回归和回滚判断。
- 决策：不覆盖或改写 `CFG-RERANK-PRO` 的原始响应、汇总和复核；新结果仅在阶段 4B-1 目录保存。

## DEC-4B1-003：P0 必须先执行 BFF 门禁

- 日期：2026-10-24
- 状态：已决定
- 依据：Pro 的原始回答也存在 P0 首段止损失败，证明不能依赖生成模型自行安全兜底。
- 决策：所有 P0 样本在 Dify 调用前短路；R2/R3 继续由 BFF 规则门禁和人工责任链控制。

## DEC-4B1-004：引用缺失不得继续放行

- 日期：2026-10-24
- 状态：已决定
- 依据：可追溯引用是售后规则结论的必要交付条件。
- 决策：应引任务缺少可解析引用时，强制降级为 `NEEDS_CLARIFICATION` 或 `NO_ANSWER`。

## DEC-4B1-005：模型名通过服务端配置注入

- 日期：2026-10-24
- 状态：已决定
- 依据：避免前端泄露、环境不可切换和业务代码与供应商耦合。
- 决策：模型名只来自 `RAG_GENERATION_MODEL`；配置变量不得进入 HTML、前端 JavaScript 或提交凭据。

## 保留风险

- 该结论只覆盖当前 17 条公开资料模拟任务，不外推为客户生产准确率。
- POC-R03 的 Apple 14 天规则引用仍未直接命中，后续 RAG 知识切片与问答模板需继续改进。
- 两轮文本存在随机差异，未来发布前仍需加入更多渠道、时间和状态组合的回归集。

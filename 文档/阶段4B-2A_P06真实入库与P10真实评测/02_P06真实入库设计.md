# P06 真实入库设计

## 1. 边界

- BFF 只接受 CANDIDATE manifest 中的 `doc_id`、`src_id` 和版本；
- BFF 按 manifest 读取本地文件，不接受浏览器提交任意路径；
- 上传前校验文件 SHA-256；
- Dataset Key 只在服务端 Dataset Adapter 中使用；
- P06 的文档状态与 Dify 索引状态分开保存。

## 2. 状态

文档状态：

- `DOCUMENT_UPLOADING`
- `DOCUMENT_INDEXING`
- `DOCUMENT_RETRYING`
- `DOCUMENT_READY`
- `DOCUMENT_FAILED`

Dify 索引状态：

- `QUEUED`
- `PARSING`
- `CHUNKING`
- `INDEXING`
- `READY`
- `FAILED`

只有 `DOCUMENT_READY + READY` 时 `publishable=true`。其他状态一律不可发布。

## 3. 幂等与重试

- 同一 `Idempotency-Key + doc_id + src_id + source_version` 返回原入库任务；
- 首次上传使用 Dify `create-by-file`；
- 失败重试使用同一 Dify `document_id` 调用 `update-by-file`；
- 重试不会创建第二个文档；
- 重试请求使用独立幂等键，重复提交返回首次重试结果；
- 失败保留步骤、错误码、错误信息和是否可重试。

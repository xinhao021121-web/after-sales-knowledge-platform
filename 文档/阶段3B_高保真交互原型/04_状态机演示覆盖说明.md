# 状态机演示覆盖说明

机器可读映射：[04_状态机演示覆盖表.csv](04_状态机演示覆盖表.csv)

## 覆盖范围

覆盖 PRD V1.4 的全部 57 个对象自身状态，并按 ASQ、ESC、SRC、KB、CASE、CASE_LINK、EVAL、REL 分组映射到页面、用户可见下一步、失败恢复和关联演示脚本。

## CASE_LINK 基数覆盖

| 场景 | 界面证据 | 演示路径 |
|---|---|---|
| 0 LINK | P09 显示“0 LINK”和受控双角色关闭入口 | D07、D14 |
| 1 LINK | P09 显示单条修复轨道和当前活动状态 | D07 |
| N LINK | P09 显示多个 knowledge_item 轨道、聚合门禁和当前活动/失败数量 | D07、D08、D09 |

## 状态验收

- 非终态必须有用户可见的下一步；
- 失败态必须保留证据并指向恢复或升级动作；
- 终态只允许查看历史或创建后继对象；
- 页面展示统一使用“中文含义 + 次级代码”。

## 本轮关键状态约束

| 对象 | 合法推进 | 禁止行为 | 自动验证 |
|---|---|---|---|
| ASQ | `CONTEXT_PENDING → ASSESSING → ADVICE_PENDING → RESPONDED` | 上下文未完成时显示或执行发送；同一页面出现第二个 ASQ 主状态 | 读取 localStorage 断言状态、C2/C3、缺失字段和发送按钮 |
| EVAL | `PLANNED → RUNNING → PASSED / FAILED / BLOCKED` | 从 PLANNED 直接生成结果；非运行态中止 | 调用非法转换并断言状态未变化、拒绝审计存在 |
| SRC | `REGISTERED → REVIEW_REQUIRED / ACTIVE` | 五项条件未满足时激活 | 表单登记、失败激活、成功激活和替代版本均断言 localStorage |
| REL/LINK/CASE | EVAL 结果后同步变化 | 只更新最终文案、不更新关联对象 | 结果后读取 EVAL、KB、REL、LINK、CASE 状态 |
| 权限 | 管理员变更成员技术角色 | 自审自批、管理员发布、普通角色关闭 R3 | 成功变更和三类拒绝均断言对象状态及审计 |

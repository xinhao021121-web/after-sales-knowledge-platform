# 视觉方向与设计令牌

日期：2026-10-23
适用产品：企业级售后知识协作平台
当前状态：方向 A 已选定（项目负责人与导师确认）；方向 B 仅保留为历史比较，不再维护

## 1. 共同视觉定位

- 企业级专业工具，不做营销官网；
- 高信息密度但保持明确层级；
- 风险、证据、状态和责任优先于装饰；
- 主强调色最多一个；
- 风险色只用于 R2/R3、不可逆错误和安全阻断；
- 不使用附件项目或参考品牌的颜色、文案、布局和资产；
- 所有页面采用模拟数据，不暗示真实客户或业务结果。

## 1.1 方向 A 收口规则

- 深色侧栏、浅色工作区、单一蓝色主操作固定为方向 A 的基础；
- 页面标题统一为现代无衬线，桌面端控制在 28-32px；
- 所有状态使用“中文含义 + 次级代码”，例如“建议待确认 / ASQ_ADVICE_PENDING”；
- 统一使用“风险优先条 + 证据/状态轨道”作为跨页面记忆点，其中风险优先条固定位于关键任务首屏，证据/状态轨道串联上下文、风险、LINK 与发布状态；
- 主任务区以层级表面、分隔线和留白组织，不为每个信息块重复使用白色圆角卡片；
- 卡片只用于独立可操作对象、风险提示和明确的上下文区域；
- 顶栏使用模拟企业身份“澄明服务科技”；演示环境及非 Apple 项目说明只出现在预览工具区；
- 产品顶栏环境标签固定为“模拟环境”；展示模式只保留轻量模式切换，不显示 FR、脚本入口和技术页脚；
- 不采用任何第三方品牌的标志、色板、文案或页面结构。

## 2. 方向 A：深色控制台

### 气质

像一套全天候使用的专业控制台：导航退后，任务和证据前置；状态高密度但层级稳定；风险区域明确但不把整个界面染红。

### 设计令牌

| Token | 值 | 用途 |
|---|---|---|
| `--nav` | `#121820` | 深色导航和顶部系统栏 |
| `--canvas` | `#F4F6F8` | 浅色工作区背景 |
| `--surface` | `#FFFFFF` | 主要内容表面 |
| `--ink` | `#17202A` | 主文本 |
| `--muted` | `#66727F` | 次要说明 |
| `--line` | `#D8E0E8` | 分隔线和边框 |
| `--accent` | `#2F6FED` | 唯一主强调色、主操作和选中态 |
| `--accent-soft` | `#EAF0FF` | 选中背景和低强度提示 |
| `--risk` | `#BF3A30` | 只表示 R2/R3、安全和不可逆错误 |
| `--risk-soft` | `#FBECEA` | 风险背景 |
| `radius` | `14px / 9px` | 面板 / 控件 |

### 字体与尺度

- 主体：`Aptos`, `Segoe UI Variable`, `PingFang SC`, `Microsoft YaHei`；
- 页面标题：28-32px；
- 区块标题：17-20px；
- 正文：12-14px；
- 元数据：10-11px；
- ID 可使用等宽字体，但仅限对象标识和状态码。

### 布局

```text
┌──────────── 深色 Product Bar ────────────┐
│ 产品标识          环境  通知  当前角色    │
├──────────── 预览控制条（评审专用）────────┤
├────────┬───────────────────────────────┤
│深色导航│ 浅色工作区：标题 / 风险 / 证据 │
│角色专属│ 内容主列 + 上下文辅助列        │
│4-6项   │                               │
└────────┴───────────────────────────────┘
```

### 适用判断

- 优点：扫描效率高，风险与证据容易获得稳定位置；适合客服主管、知识运营和全天候操作；
- 风险：深色侧栏在 320px 下需要折叠为横向导航；
- 当前预览已处理该窄屏行为。

## 3. 方向 B：浅色编辑台

### 气质

像一份清晰的编辑式工作手册：浅色全局导航、较大的标题和留白，内容通过细线、分栏和排版建立层级；蓝绿色只用于选中与主操作。

### 设计令牌

| Token | 值 | 用途 |
|---|---|---|
| `--canvas` | `#F3F5F1` | 带轻微暖度的浅色背景 |
| `--surface` | `#FFFFFF` | 内容表面 |
| `--surface-soft` | `#E9EFEB` | 预览栏和柔性分隔 |
| `--ink` | `#15201B` | 主文本 |
| `--muted` | `#5F6C65` | 次要说明 |
| `--line` | `#D3DDD6` | 分隔线 |
| `--accent` | `#0D6F68` | 唯一蓝绿色强调 |
| `--accent-soft` | `#E3F1EE` | 强调背景 |
| `--risk` | `#B43A31` | 只表示 R2/R3、安全和不可逆错误 |
| `--radius` | `4px` | 控件和结构块 |

### 字体与尺度

- 标题：`Noto Serif SC`, `Songti SC`, `Georgia`；
- 正文：`Aptos`, `Segoe UI Variable`, `PingFang SC`, `Microsoft YaHei`；
- 页面标题：34-58px；
- 区块标题：19px；
- 正文：12-14px；
- 元数据：10-11px。

### 布局

```text
┌──────────── 浅色 Product Bar ────────────┐
│ 产品标识          环境  通知  当前角色    │
├──────────── 预览控制条（评审专用）────────┤
│ 横向角色导航：今日 / 任务 / 风险 / 案例   │
├──────────────────────────────────────────┤
│ 大标题 / 说明                             │
│ 风险线 → 指标 → 细线分区 → 右侧上下文     │
│ 不使用大量同一圆角卡片                     │
└──────────────────────────────────────────┘
```

### 适用判断

- 优点：层级更有编辑感，页面说明和证据阅读体验更从容；
- 风险：大标题与纵向分区会增加长页面高度，密集任务切换效率弱于 A；
- 当前预览在 320px 下仍保持可读，但页面明显更长。

## 4. 已选定方向

项目负责人与导师已选择 **方向 A：深色控制台**。后续 P01-P13 只扩展方向 A，不并行维护方向 B。

选择依据：

1. 深色导航与浅色工作区适合长时间、高密度任务处理；
2. 风险区、证据和状态在页面中拥有稳定位置；
3. 单一蓝色主操作不与仅用于安全风险的红色产生竞争；
4. 已通过 1440px 与 320px 代表页面检查。

## 5. 核心组件说明

| 组件 | 结构职责 | 使用规则 |
|---|---|---|
| 产品顶栏 | 模拟企业身份、环境入口、通知和当前用户 | 不显示内部项目免责声明；免责声明放在预览工具区 |
| 角色导航 | 当前活动角色可访问的工作面 | 不显示无权限入口；窄屏转为横向滚动导航 |
| 风险优先条 | 风险等级、首要止损或最高优先任务 | 只用于需要先处理的风险或阻断，不做普通装饰 |
| 证据/状态轨道 | 串联上下文、证据、风险、LINK、评测和发布 | 只展示真实存在的对象和下一步，非终态必须有动作 |
| 分区表面 | 组织主任务、证据、审核和审计 | 使用分隔线、留白和标题层级，不重复堆叠相同卡片 |
| 对象卡 | 仅承载独立可操作对象或风险提示 | 不用于普通说明文字 |
| 状态徽标 | 中文含义 + 次级代码 | 颜色只辅助识别，文字和代码必须完整 |
| 页面内反馈 | 成功、阻断、冲突、权限或降级结果 | 必须与对象状态同时变化，不用 toast 代替 |
| 数据表 | 队列、权限和审计的高密度扫描 | 表头明确，窄屏容器允许局部横向滚动 |
| 演示抽屉 | 15 条脚本的场景入口 | 属于评审工具，不作为正式产品导航 |

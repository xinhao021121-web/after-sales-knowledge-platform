# 可访问性与响应式验收

日期：2026-10-24

## 1. 键盘

- 页面首个焦点为“跳到主内容”；
- Enter 激活跳转后焦点进入页面 `h1`；
- 页面导航、角色切换、页面状态切换、ADV 发送、风险止损、CASE 查看、发布拒绝/激活均可用键盘完成；
- 展示/评审模式切换、来源登记表单和成员角色变更表单均可通过键盘完成；
- 所有交互元素有可见 `:focus-visible` 样式；
- `Escape` 非必需，因为演示脚本抽屉提供可见关闭按钮；
- 浏览器重建页面后将焦点恢复到主标题或页面内结果。

## 2. 语义与错误

- 使用 `header`、`nav`、`main`、`section`、`table` 等语义元素；
- 所有按钮有可理解文本，图标不作为唯一可访问名称；
- 状态徽标包含中文含义和次级代码；
- 页面内结果通过 `role="status"` 的 live region 宣告，不以 toast 代替；
- 加载态设置 `aria-busy="true"`；
- 表单字段有可见标签；
- 来源登记使用原生 `form`、命名输入控件和可见提交按钮；
- 展示模式隐藏评审工具时仍保留有名称的模式切换控件；
- 无权限页面只显示最小说明。

## 3. 响应式

- 评审截图覆盖 1440px 和 320px；
- 320px 下侧栏变为角色化横向导航；
- 所有页面 `documentElement.scrollWidth <= window.innerWidth + 1`；
- 大表格允许容器局部横向滚动，正文和主操作不溢出；
- CASE LINK、风险事实、状态轨道在窄屏纵向堆叠；
- 重要主操作保持在内容流中，不固定在屏幕外。
- 来源表单和权限表单在 320px 下变为单列，结果不新增横向溢出。

## 4. 状态表达

- R2/R3 使用红线和文字“R3 安全风险”，不只依赖红色；
- 成功只在对象状态更新后出现；
- 拒绝、失败和回退使用专门的页面内状态块；
- 状态同时显示中文和代码，例如“待发布 / LINK_PENDING_RELEASE”；
- 空态、异常态与无权限态互不混用。
- 展示模式不显示 FR 编号、模拟按钮、演示脚本、技术页脚和“非 Apple 项目”说明。

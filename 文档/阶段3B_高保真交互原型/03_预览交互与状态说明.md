# 预览交互与状态说明

日期：2026-10-23

## 1. 全局交互

| 交互 | 行为 | 状态保存 |
|---|---|---|
| 页面页签 | P01/P03/P05/P09 切换 | `pages.direction` |
| URL hash | `#P01` 等直接打开页面 | 与页面状态同步 |
| 角色切换 | 更新角色、默认页面和导航 | `role` |
| 重置演示 | 恢复一线客服与 P01 | 清空本原型保存状态 |
| 浏览器刷新 | 恢复最近角色、页面、发送动作 | `localStorage` |

存储键：`stage3b-preview-state-v1`。

## 2. 关键状态

### P03 ADV 发送

- 一线、售后和主管可发送；
- 主管 CTX 显示只读说明；
- 发送后按钮变为“已发送，待客户反馈”；
- 行内结果明确说明 `ADV-v2 + CTX-v3 + EVD-02 → ASQ_RESPONDED`；
- 刷新后保持已发送状态；
- 不使用 toast 代替状态。

### P05 风险止损

- R3 风险持续存在；
- 发送止损后只更新“止损已发送”，风险仍保持 R3，不显示“风险已关闭”；
- 关闭仍要求安全责任人；
- 刷新后保持止损已发送状态。

### P09 CASE 聚合

- 同时展示 `LINK_RELEASED`、`LINK_OPEN`、`LINK_FAILED`；
- 关闭按钮禁用；
- 页面内明确显示“仍有活动 LINK，最新 LINK 为 FAILED”，不是用弹窗阻止。

## 3. 角色差异

| 角色 | 导航差异示例 | 动作差异 |
|---|---|---|
| 一线客服 | 今日、售后任务、风险、案例只读 | 可编辑 CTX、发送 ADV |
| 售后专员 | 今日、售后任务、风险、案例只读 | 可编辑 CTX、发送 ADV |
| 客服主管 | 今日、任务确认、风险、案例、发布 | CTX 只读；可发送 ADV；R3 关闭受限 |
| 业务/渠道负责人 | 待审口径、发布审批、案例影响 | 不显示客服发送操作 |
| 知识运营 | 今日、任务只读、风险影响、案例链路 | 可维护 CASE/LINK |
| AI 评测人员 | 评测中心、案例只读、发布证据 | 无政策和关闭权限 |
| 法务/安全责任人 | 今日、R3 风险、案例证据、范围审计 | 可确认 R3；无普通客服动作 |
| 系统管理员 | 今日、权限、审计与运行、集成状态 | 无业务审批与发布 |

# 预览入口与评审指南

日期：2026-10-23

## 1. 如何打开

直接用 Chrome 或 Edge 打开：

- 方向 A：[previews/direction-a.html](previews/direction-a.html)
- 方向 B：[previews/direction-b.html](previews/direction-b.html)
- 方向对比入口：[previews/index.html](previews/index.html)

文件无需构建、无需安装依赖，可直接通过 `file://` 打开。预览资源全部使用本地 CSS 和 JavaScript。

## 2. 预览范围

每个方向当前包含：

- P01 今日工作台；
- P03 售后协作任务；
- P05 风险升级单；
- P09 案例与修复链路。

这不是完整 13 页原型。项目负责人确认方向后，才扩展全部页面和完整流程。

## 3. 可操作内容

- 顶部 P01/P03/P05/P09 为视觉方向评审页签；
- “以角色查看”提供 8 类角色；
- 左侧或顶部导航随角色变化；
- URL hash 支持 `#P01`、`#P03`、`#P05`、`#P09` 深链；
- 关键页面和角色存入 `localStorage`，刷新后恢复；
- P03 可演示确认发送 ADV，并显示与对象状态一致的行内结果；
- P05 可演示发送止损，风险仍保持 R3，不会显示为已关闭；
- P09 显示 0/1/N 修复轨道的差异和禁止关闭原因。

## 4. 评审重点

1. 导航是否应长期占用深色侧栏，或使用浅色横向导航；
2. 高密度状态下，证据、状态和下一步是否仍容易扫读；
3. 风险色是否只在真正风险区域出现；
4. 页面标题与数据密度是否符合企业长期使用；
5. 320px 下是否仍能完成主要判断；
6. 哪个方向更适合扩展到全部 13 页。

## 5. 数据与边界

- 所有客户、ASQ、ESC、KB、EVAL、REL 和 CASE 均为模拟演示数据；
- 不接真实 RAG、客户系统或内部工单；
- 页面中的证据与状态用于 UI 演示，不代表真实业务结果；
- 无联网依赖、无外部字体、无第三方脚本。

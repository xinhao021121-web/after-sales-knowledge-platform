## 2. 自动化验证

执行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\tests\validate-stage3b-preview.ps1
```

验证内容：

- 两个方向均可直接加载；
- 两个方向均可通过 `file://` 直接打开，也可通过本地 HTTP 预览；
- P01/P03/P05/P09 均可通过页签和 hash 深链打开；
- 角色切换会更新导航与动作权限；

- ADV 发送和止损发送在刷新后由 localStorage 恢复；
- 键盘跳转链接把焦点移到页面主标题；
- 1440px 和 320px 均无水平溢出；
- 16 张截图存在且宽度分别为 1440/320；
- 页面无远程字体、图片或脚本依赖。

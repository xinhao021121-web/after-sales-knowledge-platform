# 澄明服务科技：售后知识协作平台

公开售后资料驱动的 **模拟企业内部项目**，不是真实企业客户系统，也不代表生产上线结果。

## 项目一句话介绍

面向一线客服、售后、知识运营和安全责任人的可追溯 RAG 售后协作原型，把客户上下文、知识证据、风险止损、人工确认、评测与知识发布串成一条可审计闭环。

## 要解决的问题与目标用户

售后问题往往同时受商品、渠道、时间、安全和知识版本影响。普通聊天机器人只关注“生成一段答案”，而本项目关注：

- 判断所需的客户上下文是否齐全；
- 回答是否有可追溯的有效知识来源；
- 高风险事件是否在生成内容前止损；
- 建议是否经过有权限的人确认；
- 失败问题是否进入知识修复、评测、发布和回滚闭环。

主要用户：一线客服、售后专员、知识运营、客服主管、业务/渠道负责人、法务/安全责任人、AI 评测人员、系统管理员。

## 为什么不是普通聊天机器人

普通问答只解决“怎么回答”。本项目把一次售后处理拆成可追踪对象与门禁：

```text
客户诉求 → 上下文快照 → 检索证据 → 条件化建议 → 人工确认
         ↘ R2/R3 风险 → 前置止损与升级
问题反馈 → CASE → 知识修复 → 评测 → 发布/回滚 → 审计
```

P0 安全、权限、过期知识、冲突、引用和供应商错误都由系统门禁控制，不能依赖模型自行保证。
